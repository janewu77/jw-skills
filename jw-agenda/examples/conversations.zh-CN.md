# 对话示例

本文档展示了如何使用自然语言与 jw-agenda 技能进行交互的完整示例。

## 示例 1：生成周规划

**用户**："生成本周计划"

**助手**（使用 `jw-agenda-weekly-plan`）：
- 读取 `monthly/2026-02-plan.md` 获取本周目标
- 检查 `weekly/Week5-review.md` 查看上周的延续任务
- 创建 `weekly/Week6-plan.md`，包含逐日分解
- 根据优先级将任务分配到具体日期

**输出**：创建 `weekly/Week6-plan.md`，包含：
- 概览部分（重点和目标）
- 任务列表表格（优先级和状态）
- 逐日分解（周一到周日）
- 来源标记（显示任务来源）

**用户**："把申请跟踪系统设置移到周五"

**助手**（使用 `jw-agenda-daily-todo`）：
- 读取 `weekly/Week6-plan.md`
- 从当前日期移除该任务
- 添加到周五部分
- 更新周规划文件
- 确认更改

**输出**："已将'设置求职申请跟踪系统'移至周五（2026-02-06）。已更新 Week6-plan.md。"

## 示例 2：日常进度汇报

**用户**："今天完成了研究 3 家公司，提交了前 3 份申请。还需要练习英语。对进展感到满意！"

**助手**（使用 `jw-agenda-daily-log`）：
- 读取 `daily/2026-02-05-todo.md` 查看计划任务
- 生成 `daily/2026-02-05-log.md`，包含：
  - 已完成任务部分（标记为完成）
  - 基于报告活动的时间分配
  - 学习/产出部分
  - 未完成任务（英语练习）
  - 总结和反思
  - 笔记部分（记录感受/想法）
- 更新 `daily/2026-02-05-todo.md` 的复选框：
  - ✅ 研究剩余 3 家目标公司
  - ✅ 提交前 3 份求职申请
  - ⬜ 练习英语口语 30 分钟（移至未完成）

**输出**：
- 创建了 `daily/2026-02-05-log.md` 结构化日志
- 更新了 `daily/2026-02-05-todo.md` 复选框
- 消息："已记录你的进展！创建了今天的日志并更新了待办事项。英语练习仍待完成——你想现在做还是移到明天？"

## 示例 3：生成今日待办

**用户**："生成今天的计划"

**助手**（使用 `jw-agenda-daily-todo`）：
- 读取 `weekly/Week6-plan.md` 查找今天的任务
- 检查 `daily/2026-02-04-log.md` 查看昨天未完成项
- 读取 `monthly/2026-02-plan.md` 获取上下文
- 生成 `daily/2026-02-05-todo.md`，包含：
  - 时间表（时段）
  - 高优先级任务（来自周规划）
  - 中优先级任务
  - 低优先级任务
  - 来源标记（显示来源）

**输出**：创建 `daily/2026-02-05-todo.md`：
```
# 待办事项 - 2026-02-05

## 🔴 高优先级
- [ ] 研究剩余 3 家目标公司 *(来自规划)*
- [ ] 提交前 3 份求职申请 *(来自规划)*

## 🟡 中优先级
- [ ] 练习英语口语 30 分钟 *(来自规划)*
```

## 示例 4：添加临时任务

**用户**："加一项：再次审查申请材料"

**助手**（使用 `jw-agenda-daily-todo`）：
- 确定这是今天的任务（未指定日期）
- 添加到 `daily/2026-02-05-todo.md` 的低优先级部分
- 标记为 *(临时追加)*
- 确认添加

**输出**："已将'再次审查申请材料'添加到今天的待办事项（低优先级）。"

## 示例 5：周总结

**用户**："周总结"

**助手**（使用 `jw-agenda-weekly-review`）：
- 读取本周所有日志（`daily/2026-02-02-log.md` 到 `daily/2026-02-08-log.md`）
- 读取 `weekly/Week6-plan.md` 对比计划与实际
- 生成 `weekly/Week6-review.md`，包含：
  - 整体完成率
  - 已完成任务列表
  - 未完成任务列表
  - 时间分配总结
  - 学习与产出
  - 转入下周的事项

**输出**：创建 `weekly/Week6-review.md`：
```
# 第 6 周总结 (2026-02-02 ~ 2026-02-08)

## 整体概览
- **完成率**：80%（已完成 4 / 总计 5 项）
- **数据覆盖**：5/7 天有日志记录
- **本周亮点**：成功提交第一批求职申请

## 转入下周
- 设置求职申请跟踪系统（延续）
```

## 示例 6：计划一致性检查

**用户**："同步规划"

**助手**（使用 `jw-agenda-planning-sync`）：
- 读取 `daily/2026-02-05-todo.md`
- 读取 `weekly/Week6-plan.md`
- 读取 `monthly/2026-02-plan.md`
- 比较三个层级中的任务
- 识别不一致：
  - 在日待办中但不在周规划中的任务
  - 在日志中标记完成但在周规划中仍显示进行中的任务
  - 优先级不匹配
- 显示不一致并询问确认后再修复

**输出**：
```
发现 2 处不一致：

1. "审查申请材料"在日待办中但不在周规划中
   → 添加到周规划？(y/n)

2. "研究公司"在日志中标记完成但在周规划中仍显示进行中
   → 更新周规划状态？(y/n)
```

## 自然语言使用技巧

- **具体明确**："生成本周计划"比"计划"更好
- **随意自然**："今天完成了 X，还有 Y 要做"完全可以
- **使用上下文**：助手理解"今天"、"明天"、"本周"、"下周"
- **组合操作**："把 X 移到周三，再加一个 Y 到明天"可以
- **提问**："今天有什么待办？"或"这周进展如何？"

这些技能设计为理解自然、对话式的语言，同时保持数据一致性。
