# Summary Categories Configuration

daily-log and weekly-review use these categories to summarize the "Learning/Output" section. Modify this file to adjust the category dimensions for all future logs and weekly reviews.

## Categories

- Job Applications
- English Training
- German Learning
- Technical Learning & Practice
- Reading / Content Creation
- Exercise / Social

## Configuration Notes

- One category per line, starting with `- `
- Category names are displayed as sub-headings in logs and weekly reviews
- Categories can be added, removed, or reordered at any time; the agent will generate corresponding sub-paragraphs based on this list
- If a category has no content for the day/week, it shows "None" or is omitted (decided by the agent based on actual data)
- Recommended to keep 4–8 categories; too many will make logs verbose
