# Summary Categories / 总结分类配置

daily-log 和 weekly-review 在「学习/产出」模块中按此分类进行总结。修改本文件即可调整所有未来生成的日志和周总结的分类维度。

## Categories / 分类列表

- 投递
- 英文训练
- 德语学习
- 技术学习与应用
- 阅读/内容创作
- 运动/社交

## Configuration Notes / 配置说明

- 每行一个分类，以 `- ` 开头
- 分类名称即为日志和周总结中子标题的显示文字
- 可随时增删、调整顺序，agent 会按此列表生成对应子段落
- 当天/当周若某分类无内容，显示「无」或省略（由 agent 根据实际数据决定）
- 建议分类数量控制在 4–8 个，过多会导致日志冗长
